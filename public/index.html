Endpoint

Lima endpoint + health check, semua GET, semuanya punya cache publik. Spesifikasi mesin-terbaca di /openapi.json (live: /api/openapi.json).

GET/api/libur
Cek satu tanggal, rekap setahun, satu bulan, N libur terdekat, atau rentang tanggal.
date=YYYY-MM-DDyear=2026month=3next=1&count=3from&totype=allformat=csv
GET/api/imsak
Jadwal imsakiyah 30 hari Ramadan: imsak, subuh, zuhur, ashar, magrib, isya.
city=jakartayear=2026date=2026-03-01format=csv
GET/api/kota
Daftar kota beserta provinsi, zona waktu, dan tahun imsakiyah yang tersedia.
no parameter
GET/api/libur.ics
iCalendar (RFC 5545) untuk subscribe ke Google / Apple Calendar.
year=2026type=allnext=1 & count=3

Coba langsung

Playground memanggil API sungguhan di browser kamu. URL ikut terisi otomatis sehingga bisa dibagikan (deep-link).

Isi tanggal lalu tekan “Kirim”.
Isi rentang lalu tekan “Kirim”.
Pilih kota lalu tekan “Kirim”.
Klik “Unduh .ics” maka file libur-indonesia.ics akan diunduh. Masukkan ke Google Calendar › Settings › Import & export, atau buka di Apple Calendar.

cURL

  • Panel monitoring
  • Task scheduler / cron
curl "https://data-libur-nasional-indonesia.vercel.app/api/libur?date=2026-08-17" | python3 -m json.tool

Python

  • Analisis data / ML
  • Jadwal otomatis
from hapilibur import is_libur, imsak, upcoming
is_libur("2026-08-17")   # True
upcoming()               # libur terdekat

JavaScript / Fetch

  • Web app / widget
  • Kalender internal

const data = await r.json();
