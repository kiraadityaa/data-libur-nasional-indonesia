Data Libur Nasional Indonesia 🇮🇩

REST API gratis untuk hari libur nasional, cuti bersama, dan jadwal imsakiyah Indonesia. Data bersumber resmi: SKB 3 Menteri (2026) dan Bimas Islam Kementerian Agama RI.

Lihat source di GitHub

Endpoint

1. Cek satu tanggal

GET /api/libur?date=2026-08-17

→ { "is_holiday": true, "libur_nasional": { "date": "2026-08-17", "name": "Hari Proklamasi Kemerdekaan RI" } }

2. Semua libur satu tahun

GET /api/libur?year=2026

→ 17 hari libur nasional + 8 cuti bersama tahun 2026

3. Jadwal imsakiyah kota

GET /api/imsak?city=jakarta&year=2026

Kota tersedia: jakarta, surabaya. Setiap jadwal memuat imsak, subuh, zuhur, ashar, magrib, isya.

Contoh pakai cURL

curl "https://data-libur-nasional-indonesia.vercel.app/api/libur?date=2026-08-17"
